Android 虚拟机 Root 配置指南

发表于2025-06-11|更新于2026-07-17|Android
|总字数:269|阅读时长:1分钟|浏览量:|评论数:

🛠️ 工具介绍

开源工具：RootAVD

  • 项目地址：RootAVD - GitHub
  • 专门用于Android虚拟机Root的自动化工具
  • 支持多种Android API版本

🚀 操作流程

📱 选择虚拟机配置

推荐配置：

  • Android API 25 (Android 7.1)
  • 架构：64位
  • 类型：Google APIs
# 创建虚拟机后建议重新命名
# 例如：RootAvd25、RootAvdXX

版本选择说明：
经测试API 35、34版本可能遇到问题，API 25稳定性较好

🔧 执行Root操作

自动Root流程：

  1. 运行RootAVD脚本选择对应镜像
  2. 工具会自动安装Magisk
  3. 打开Magisk统一权限，等待5秒自动重启

⚙️ 重要配置

参考配置说明：
详见 RootAVD Notes

🎯 Magisk设置

Magisk配置步骤：

# 1. 勾选启用Magisk
# 2. Magisk App -> Settings -> Multiuser Mode -> User-Independent
# 3. 重启AVD
# 4. 在Magisk中选择reboot

🔓 系统写入权限

启用系统写入权限：

# 以可写系统模式运行AVD
emulator -writable-system -avd Avd71

# 后续可通过mount、remount挂载操作
# 实现系统文件的增删改功能
