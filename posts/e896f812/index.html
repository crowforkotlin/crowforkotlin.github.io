③ Hexo Quick Deploy 脚本

发表于2025-12-18|更新于2026-08-19|Hexo
|总字数:230|阅读时长:1分钟|浏览量:|评论数:

本仓库通过统一的 pnpm 命令部署站点：

pnpm run deploy

pnpm 11 的 pnpm deploy 是工作区包部署命令，不能作为 Hexo 站点的发布入口。使用 pnpm run deploy 可以明确调用 package.json 中的站点部署脚本。

该命令调用 scripts/deploy.sh，并按以下顺序执行：

  1. 使用 scripts/doctor.sh production 验证生产环境和部署配置。
  2. 清理 Hexo 缓存与旧构建文件。
  3. 使用 hexo generate --bail 生成静态文件。
  4. 检查 public/index.html 和 public/CNAME。
  5. 使用 hexo deploy 将静态文件发布到站点仓库。

部署前可独立执行生产构建：

pnpm check:production
pnpm clean
pnpm build
pnpm preview

自定义域名保存在 source/CNAME，构建时会复制到 public/CNAME。部署脚本不提交、拉取或推送源码仓库。源码变更应通过独立的 Git 工作流提交，站点部署只负责更新生成物仓库。
